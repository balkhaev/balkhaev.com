У любого бизнеса есть десяток повторяющихся процессов, на которых теряются деньги: заявка ждёт менеджера три часа, неудавшийся платёж никто не замечает, отчёт собирают руками по понедельникам. Каждый из них можно автоматизировать за вечер, а потом полгода разгребать последствия: потерянные вебхуки, двойные списания, бот, который упал в пятницу и молчал до понедельника.

В этом цикле мы строим автоматизации правильно, с фундамента. Сначала разбираемся, какие из них действительно окупаются, затем поднимаем сервер, базу и деплой по пушу, пишем надёжное ядро с очередью и повторами, и уже на нём собираем конкретные автоматизации: лиды, оплаты, поддержку, отчёты. Последняя часть про то, как всё это эксплуатировать и сколько оно стоит.

Стек простой и без фреймворков: TypeScript и Bun, Postgres как база и очередь, Docker Compose на одном VPS, Caddy для HTTPS, GitHub Actions для деплоя, Telegram для уведомлений и Claude по API там, где нужно понимать текст. Каждая часть заканчивается кодом, который можно запустить, а следующая продолжает его.
