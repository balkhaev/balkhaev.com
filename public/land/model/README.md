# 3D-долина для кейса «Алтай. Живая земля»

Сцена `plan` и рендерер взяты из `balkhaev/altay` на коммите
`7b9ac2409b2f61110366f74e2138813877ead986`. Она использует исходную
геометрию рельефа и посёлка, текстуры, модели леса и данные генплана.

Для обновления скопируйте из проекта Алтая ассеты сцены `plan`, её общий
буфер и текстуры. Замените префикс `/models/anos-v3/` на `/land/model/` в
модулях и манифестах сцены, включая шаблон `SHARED_FILE` в `mobile-scenes.mjs`.
Пути снимков из `land-plan.mjs` направьте в `/land/model/images/`.
Соберите `public/valley-scene.mjs` командой
`bun build public/valley-scene.mjs --minify --target=browser --format=esm`
и укажите имя нового файла с ревизией в `/land/preview.js`.

Лицензия Three.js прилагается. Источники географических данных перечислены
в манифесте сцены и под предпросмотром.
